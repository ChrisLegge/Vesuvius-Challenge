# Scripts

This folder keeps project utilities that supported notebook generation, validation, and repair.

| Script | Purpose |
|---|---|
| `build_v3_notebooks.py` | Generates the v3 model training and prediction notebooks |
| `verify_train_fixes.py` | Lightweight verification utility for training fixes |
| `fix_train_val.py` | Training/validation repair utility from the project iteration history |
| `fix_train_val_bc.py` | Boundary-condition related training/validation repair utility |

These scripts are retained for transparency. The primary entry points for the project are the notebooks.
