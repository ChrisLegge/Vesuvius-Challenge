# Notebooks

The notebooks are ordered as a readable research workflow.

| Notebook | Role |
|---|---|
| `01_train_model_a_generalist.ipynb` | Generalist training run |
| `02_train_model_b_anti_merge.ipynb` | Specialist run aimed at reducing merge/bridge errors |
| `03_train_model_c_surface_specialist.ipynb` | Surface-focused specialist run |
| `04_predict_ensemble.ipynb` | Ensemble prediction notebook |
| `production_3d_inference.ipynb` | Production-style 3D inference notebook with runtime degradation logic |

These notebooks were designed for Kaggle GPU environments and expect Kaggle-style input paths. Large data and checkpoints are intentionally excluded from Git.
